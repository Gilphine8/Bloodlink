# BloodLinks

A modern multi-page Next.js web application connecting blood donors with patients across major Kenyan hospitals (including Kenyatta National Hospital, Aga Khan, and Moi Teaching & Referral).

## Features
- Interactive Blood Finder Dashboard filtered by County and Blood Type.
- Multi-step Donor Registration workflow.
- Real-time Hospital Partner network and shortage alert system.

## Setup Instructions
1. Clone the repository
2. Install dependencies: `npm install`
3. Run local server: `npm run dev`
